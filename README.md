# Liquid stock — demo

Статический сайт «Жидкости в наличии»: бренды, вкусы, оценки, крепость. Данные лежат в `data/stock.json`, сайт к API не обращается.

Запуск: `python3 tools/serve.py 8765`, затем http://127.0.0.1:8765

Данные в `data/stock.json` демонстрационные: названия брендов и вкусов без количеств. Подключений к внешним сервисам и ключей в проекте нет.
